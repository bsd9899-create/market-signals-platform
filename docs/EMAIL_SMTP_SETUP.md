# ⚠️ هذا الملف قديم — لم يعد ينطبق على التطبيق

كان هذا المستند يوثّق حل تعارض OTP/SMTP لتسجيل دخول عبر رمز يُرسل
بالبريد الإلكتروني. **تم استبدال تسجيل الدخول بالكامل بـ Google
وApple OAuth** (راجع `docs/OAUTH_SETUP.md`)، ولم يعد التطبيق يستخدم
البريد الإلكتروني أو OTP أو Custom SMTP في رحلة تسجيل الدخول إطلاقًا.

لا حاجة لإعداد Resend أو أي مزوّد SMTP بعد الآن. تم الإبقاء على هذا
الملف فقط للسجل التاريخي؛ لا تتبع خطواته.
