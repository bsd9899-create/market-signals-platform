# هوية هِمّة البصرية

الشعار الرسمي وصل حتى الآن كصورة داخل المحادثة فقط، وليس كملف قابل
للحفظ في المستودع. الألوان والخط المستخرجة منه مطبّقة فعليًا في
`src/design-system` (انظر `colors.ts` و`typography.ts`)، لكن **الشعار
نفسه كصورة (PNG/SVG) لم يُضَف بعد**.

## الأيقونات الحالية (placeholder بهوية حقيقية، وليست الشعار النهائي)

بدل ترك أيقونة Expo الافتراضية (السهم الأزرق)، تم توليد أيقونة/سبلاش
مؤقتة عبر سكربت بايثون (`gen_icons.py`، غير مضمّن في المستودع) تستخدم
**فقط** ألوان وخط الهوية المعتمدَين فعليًا (تيل داكن `#0F2E2A` + ذهبي
`#C79A56` + خط Tajawal) — بحرف "هـ" (أول حرف من "همة") كعلامة مبدئية،
بدون اختراع أي شكل أو رمز جديد للهوية:

- `assets/icon.png` — خلفية تيل داكن + حرف "هـ" ذهبي (أيقونة iOS/Android).
- `assets/splash-icon.png` — كلمة "هِمّة" بالتيل + حرف "هـ" ذهبي، خلفية شفافة.
- `assets/android-icon-*.png` — طبقات الأيقونة المتكيّفة لأندرويد بنفس الألوان.
- `assets/favicon.png` — نفس أيقونة iOS مصغّرة (للويب فقط).

هذه الأيقونات **جاهزة لبناء EAS وتصلح للتجربة على الجهاز فعليًا**، لكنها
تبقى مؤقتة إلى حين توفر الشعار الرسمي كملف حقيقي.

## عند توفر ملف الشعار الفعلي

1. ضع نسخة SVG أو PNG بدقة عالية هنا باسم `logo.png` / `logo.svg`.
2. استبدل `assets/icon.png`, `assets/splash-icon.png`,
   `assets/android-icon-*.png`, `assets/favicon.png` بنسخ مشتقة من
   الشعار الرسمي (1024×1024 للأيقونة الرئيسية).
3. استبدل مكوّن `Wordmark` في `src/design-system/components/Wordmark.tsx`
   (نص "هِمّة" بخط Tajawal حاليًا) بصورة الشعار الحقيقية إن رغبت.
4. أعد تشغيل `npx expo prebuild --platform ios --clean` (أو ابنِ عبر EAS
   مباشرة) لتوليد الأيقونات الجديدة داخل المشروع الأصلي.
