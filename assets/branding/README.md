# هوية هِمّة البصرية

الشعار الرسمي وصل حتى الآن كصورة داخل المحادثة فقط، وليس كملف قابل
للحفظ في المستودع. الألوان والخط المستخرجة منه مطبّقة فعليًا في
`src/design-system` (انظر `colors.ts` و`typography.ts`)، لكن **الشعار
نفسه كصورة (PNG/SVG) لم يُضَف بعد**.

عند توفر الملف الفعلي:

1. ضع نسخة SVG أو PNG بدقة عالية هنا باسم `logo.png` / `logo.svg`.
2. استبدل الأيقونات المؤقتة في `assets/icon.png`, `assets/splash-icon.png`,
   `assets/android-icon-*.png` بنسخ مشتقة من الشعار الرسمي (1024×1024 للأيقونة).
3. استبدل مكوّن `Wordmark` المؤقت في `src/design-system/components/Wordmark.tsx`
   بصورة الشعار الحقيقية إن رغبت باستخدامه داخل الواجهة (شاشة الترحيب مثلاً).

حتى ذلك الحين، الأيقونات الحالية هي القالب الافتراضي من Expo كعنصر
نائب فقط وليست جزءًا من الهوية النهائية.
